## 🚀 Projects

### 📊 US Executive Insider Trading Analysis
Analysed 3,031 CEO and CFO trades across 50 US companies using the SEC EDGAR API. Benchmarked all results against the S&P 500 to control for broader market conditions. Built an interactive Tableau dashboard to present the findings.

### 📈 S&P 500 Sector Performance Analysis (2000 to 2026)
Analysed 25 years of sector performance data across all 11 S&P 500 sectors using the Alpha Vantage API. Built an interactive Tableau dashboard allowing exploration by year and sector.

### 🤖 Polymarket Copy Trading Bot
Built an autonomous trading bot that identifies and mirrors the trades of high performing arbitrage traders on Polymarket. The bot runs 24/7 on a Ubuntu VPS, includes a custom risk engine with five protective rules, sends real time alerts via a Telegram bot integration, and features a live web dashboard for performance monitoring and wallet analytics. Built using Python, Flask, SQLite, and the Polymarket and Telegram APIs.

### 🏠 UK House Price Predictor
End to end machine learning project that predicts residential property prices across England and Wales using real HM Land Registry transaction data. Achieved an R² of 64.6% using a Random Forest model and deployed as a live web application via Streamlit.
