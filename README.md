## 🚀 Featured Projects

### 🤖 Polymarket Copy Trading Bot
> Python · Flask · SQLite · Telegram API · Ubuntu VPS · REST APIs

An autonomous trading bot that identifies and mirrors the trades of high performing arbitrage traders on Polymarket, a real money prediction market platform. The bot runs 24/7 on a Ubuntu VPS, applies a five point risk engine on every trade, sends real time alerts via Telegram, and features a live web dashboard for performance monitoring and wallet analytics.

---

### 📊 US Executive Insider Trading Analysis
> Python · Pandas · SEC EDGAR API · yfinance · Tableau

Analysed 3,031 CEO and CFO trades across 50 US companies from 2023 to 2026. Benchmarked all results against the S&P 500 to control for broader market conditions. Key finding: the highest 90 day returns in the dataset came after insider sells, not buys. Built an interactive Tableau dashboard to present findings.

🔗 [GitHub](https://github.com/Akash21ch/sec-insider-trading-analysis) · [Tableau Dashboard](https://lnkd.in/e7UF6aex) · [Portfolio Site](https://lnkd.in/eDyFzEju)

### 🏠 UK House Price Predictor
> Python · Pandas · Scikit-learn · Random Forest · Streamlit

End to end machine learning project predicting residential property prices across England and Wales using real HM Land Registry data. Achieved R² of 64.6% with a Random Forest model. Deployed as a publicly accessible live web application.

🔗 [GitHub](https://github.com/Akash21ch/uk-house-price-predictor) · [Live App](https://uk-house-price-predictor.streamlit.app)
